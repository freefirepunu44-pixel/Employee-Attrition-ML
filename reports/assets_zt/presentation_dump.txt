  [Rounded Rectangle 6]: The Shifting Security Paradigm
• The Traditional Blindspot: Traditional enterprise networks rely on perimeter firewalls. Once an adversary compromises a VPN credential or Wi-Fi key, they move laterally across internal subnets and databases with zero continuous verification.
• The Zero Trust Mandate: NIST SP 800-207 establishes: "Never Trust, Always Verify." Implicit trust based on network location is eliminated; every access request is continuously evaluated against identity, endpoint posture, and real-time risk.
• Why Machine Learning is Critical: Static firewall rules cannot adapt dynamically to subtle behavioral drift, credential stuffing, or impossible travel velocities. Machine learning models score risk and anomalies in real time per request.
  [Rounded Rectangle 7]: 1. Identity Assurance
PBKDF2-SHA256 password hashing (260k rounds), live SMTP Email OTP verification, and passwordless 128D facial biometrics.
  [Rounded Rectangle 8]: 2. 16-Control Engine
Structured pipeline extracting 18 contextual security signals (device, IP reputation, impossible travel, VPN/Tor, off-hours) with typed provenance.
  [Rounded Rectangle 9]: 3. Dual-AI Risk Scoring
Tuned Random Forest Regressor (0–100 risk score) paired with Isolation Forest behavioral anomaly detection (+15 penalty).
  [Rounded Rectangle 10]: 4. Dynamic Policy Engine
Evaluates 5 database-backed rules (ALLOW, STEP-UP, DENY, BLOCK) with forward SHA-256 chained audit logs.
  [Rounded Rectangle 11]: Inbound Access Request   →   16 Controls Extracted   →   Dual-AI Risk Evaluated   →   Dynamic Policy Enforced   →   SHA-256 Audit Logged

  [Rounded Rectangle 16]: • 4. Account Reactivation: Restores legitimate operator accounts once security inquiries or credentials conclude.

  [Rounded Rectangle 8]: Client Telemetry & Biometrics
• Frontend Client: Vanilla ES6 Modular JavaScript (Zero external third-party bloat; memory tokens)
• 16 Controls: Structured pipeline returning typed provenance (verified, failed, warning, simulated)
• Biometrics Capture: HTML5 MediaDevices & Canvas API for real-time webcam video stream
• Face Verification: 128D geometric vector cosine similarity with OpenCV Haar-Cascade liveness detection
  [Rounded Rectangle 9]: Database, Auth & Cryptography
• Primary Database: SQLite with Write-Ahead Logging (WAL Mode) & strict foreign key enforcement
• Credential Security: PBKDF2-SHA256 password hashing & live SMTP Email OTP (STARTTLS port 587)
• Biometric Vault: Fernet AES-128-CBC encrypted template storage with zero plaintext retention
• Audit Integrity: Forward-chained SHA-256 tamper-evident chronological ledger with live UI verify

  [TextBox 2]: Risks, Challenges & Mitigation
Identified technical challenges and operational countermeasures
  [TextBox 4]: AI-BASED ZERO TRUST ARCHITECTURE  •  MAJOR PROJECT REVIEW
  [TextBox 5]: 11
  [Rounded Rectangle 6]: Adversarial Telemetry Manipulation
• Attackers manipulating request headers or signals to lower risk scores.: Mitigation: Enforce strict server-side feature clipping, domain normalization, and fail-closed hard rule overrides for blacklists.
  [Rounded Rectangle 7]: Biometric Spoofing (Photos & Screen Replay)
• Presenting 2D printed photographs or screens to bypass face auth.: Mitigation: Implement real-time Haar-cascade eye-blink cadence, lighting variance, micro-movement liveness verification, and fallback to Email OTP.
  [Rounded Rectangle 8]: Machine Learning Inference Latency
• Complex multi-model evaluation creating perceptible API response delay.: Mitigation: Deploy depth-capped Random Forest (bounded artifact size) loaded in-memory via Joblib, achieving ~249ms full policy decisions.
  [Rounded Rectangle 9]: Browser Privacy Masking & VPNs
• Privacy extensions masking canvas and device hardware specs.: Mitigation: Missing signals flagged honestly as unavailable/warning, elevating risk score and triggering step-up multi-factor authentication.
